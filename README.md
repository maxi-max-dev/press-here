```bash

```

```bash
npm run lint

```

## 黄金路径

打开首页后直接点击照片上的 1 / 2 / 3；切到“编辑”，可拖动标点、修改步骤标题和一句动作、增加提示或警告、调整顺序、删除并保存。右侧“贴在设备旁”的分享卡生成真实指南二维码；打开独立移动页后可逐步操作，并反馈“这一步不对”或“已解决”。回到编辑器能看到待修正步骤，修改后用“保存修正并标记已修正”完成本机闭环。咖啡机与投影仪是精修内置样例，均可一键恢复；“我的设备”支持从空画布上传本地照片、手动点击标点和粘贴或上传说明文字。

## 诚实边界

内置内容明确标为“示例解析 · 预先制作，非实时 AI”，不是运行时模型结果。自定义图片不会上传，也不会自动识别；页面明确显示“尚未自动解析”，所有标点由用户手动建立。二维码编码当前真实指南路由，但本地 Demo 不代表该路由已公网分享；自定义图片、步骤和读者反馈只保存在当前浏览器。反馈闭环是同一浏览器内的交互演示，跨设备扫码不会携带数据，也不会把手机反馈同步回编辑者。
